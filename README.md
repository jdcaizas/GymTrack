# GymTrack

GymTrack es una aplicación web para gestionar entrenamientos
y llevar un seguimiento del progreso en el gimnasio.

## Tecnologías utilizadas

- Vue.js
- NestJS
- TypeScript
- SQLite
- TypeORM

## Funcionalidades

- Registro e inicio de sesión.
- Gestión de usuarios.
- Validación de cédula ecuatoriana.
- Creación y gestión de ejercicios.
- Seguimiento de entrenamientos.

## Instalación

### Backend

```bash
cd backend
npm install
npm run start:dev
